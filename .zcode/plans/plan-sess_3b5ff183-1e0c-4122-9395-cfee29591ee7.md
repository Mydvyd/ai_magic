
## План исправлений ai_magic

Работа разбита на 7 этапов. После каждого этапа я буду отчитываться. README перепишу в конце, после всех кодовых правок, чтобы отражать финальное состояние.

---

### Этап 1: Исправление критического и средних багов

**1.1. Защита от пустого `choices` (HIGH)**
- Файлы: `client.py`, `api.py`
- Добавить проверку `response.choices` на пустоту перед `choices[0]`. Бросать кастомное исключение `ProviderError` с понятным сообщением «Provider returned no completion choices».
- Обновить docstring в `api.py`: убрать `IndexError` из Raises, заменить на `ProviderError`.

**1.2. Gemini-адаптер: ошибка при пустых candidates (MEDIUM)**
- Файл: `adapters.py`, функция `gemini_to_openai()`
- Проверить `candidates` — если пустой список, бросить `ProviderError` вместо молча-пустого ответа.

**1.3. Понятная ошибка при отсутствии поля «key» в маппинге (MEDIUM)**
- Файл: `state.py`, `_coerce()`
- Заменить голый `item["key"]` на `item.get("key")` с выбросом `ValueError("...must contain a 'key' field")`.

**1.4. Чтение числовых настроек из окружения (MEDIUM)**
- Файл: `config.py`, `from_env()`
- Добавить чтение `AI_MAGIC_TIMEOUT`, `AI_MAGIC_MAX_RETRIES`, `AI_MAGIC_MAX_CREDENTIAL_WAIT`, `AI_MAGIC_PRIMARY_MODEL`, `AI_MAGIC_FALLBACK_MODEL` из env с парсингом типов.

**1.5. Сужение `except Exception` в карусели (MEDIUM)**
- Файл: `providers.py`, `CarouselProvider.create()`
- Заменить `except Exception` на `except (httpx.TransportError, ProviderError, RateLimitError, AuthenticationError)` — только известные retryable типы. Остальное пробрасывается сразу.

**1.6. Runtime-guard на `stream=True` (MEDIUM → LOW, но полезно)**
- Файл: `client.py`, `_Completions.create()` или `ChatCompletionRequest`
- Добавить проверку: если `stream=True` в request → бросить `ValueError("Streaming is not supported")`.
